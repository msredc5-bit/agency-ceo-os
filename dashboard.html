Agency CEO OS — Demo Dashboard

Honest label: this page shows the system structure and the mock demo state. It is NOT a live control panel: no worker runs from here, nothing sends, publishes, or spends from here. Live runs happen from the command line (see README + DEPLOY.md), and every gated action still waits for Boss's word.

Chain of command

Boss (Md Mainuddin) → Main CEO Bot (BossCEO) → 4 Division Managers → 15 workers. No COO layer: at this scale the CEO + division managers already coordinate everything; a COO would duplicate the division managers' job. A COO/Chief-of-Staff layer is a later option only if the business count grows past one agency.

Provider modes

  • Mock ($0): deterministic fake answers. Used by boss-ceo/scripts/boss_run.py and by the demo when no key is set. Nothing leaves the machine.
  • Live (Muse Spark via Meta Model API): used by ceo-os demo when MODEL_API_KEY is set. One tiny call first (scripts/live_check.py), then the full demo. Token counts are printed; $ cost follows Meta's price sheet.

What is NOT here yet

  • Real tool execution: workers draft and plan through the model; they do not send email, book calendars, or call Vapi/Retell APIs by themselves.
  • 24/7 hosting: this code runs on demand from a computer. A rented server is needed only when it must run around the clock (see DEPLOY.md).
  • Real customer data: the demo uses mock data only.
